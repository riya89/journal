## 🎯 The Frankenstein Thesis

Echo is a **chimera of traditionally incompatible wellness technologies**. We've stitched together:

- 📝 **Reflective Journaling** (private, introspective)
- 🎮 **RPG Gaming** (competitive, achievement-driven)
- 🤖 **AI Therapy** (conversational, supportive)
- ✅ **Task Management** (productivity, action-oriented)
- 🏺 **Gratitude Practice** (mindfulness, present-focused)
- ⏰ **Time Capsules** (nostalgia, future-focused)
- 📊 **Data Analytics** (quantitative, pattern-seeking)
- 🌙 **Mood Tracking** (clinical, diagnostic)

**These systems shouldn't work together - but they do, beautifully.**

Through a shared data layer, every action triggers 5-7 other systems, creating compound growth effects that make the whole exponentially more powerful than the sum of its parts.

## 🔗 The Stitching

### Example: Writing a Journal Entry
```
User writes: "Feeling stressed about work"
    ↓
1. Saves to Firestore (Journaling)
2. Logs mood: 3/5 (Mood Tracking)
3. Awards 50 XP (Gamification)
4. AI analyzes text (AI Companion)
5. Updates mood chart (Analytics)
6. Checks quest progress (Gaming)
7. Updates streak (Tracking)
8. Unlocks badge if milestone (Gaming)
```

### Example: AI-Driven Task Creation
```
User chats: "I'm feeling stressed"
    ↓
1. AI checks journal history
2. Finds stress pattern (5x this month)
3. Analyzes mood correlation
4. Discovers: Mood improves 40% with breaks
5. Suggests: "Take 15-min break every 2 hours"
6. Creates task automatically
7. Tracks completion impact
```

## 🚀 Getting Started

### Prerequisites
- Node.js 16+
- npm or yarn
- Firebase account
- OpenAI API key

### Installation

1. Clone the repository
```bash
git clone https://github.com/riya89/journal.git
cd journal
```

2. Install dependencies
```bash
npm install
```

3. Set up environment variables
```bash
cp .env.example .env
# Add your Firebase and OpenAI credentials
```

4. Start the development server
```bash
npm start
```

5. Open [http://localhost:3000](http://localhost:3000)

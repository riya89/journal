## Core Features

### 1. Daily Journaling
**Location:** Home Page (Main Calendar View)

**Features:**
- **Calendar Grid:** Monthly view showing all days with visual indicators
- **Entry Status:** Color-coded cards showing which days have entries
- **Book-Style Modal:** Beautiful two-page journal interface
- **Rich Content:**
  - Title and date
  - Mood selection (1-5 scale with emojis)
  - Free-form text entry
  - Word count tracking
  - Template support
- **Entry Management:**
  - Create, edit, and delete entries
  - Read-only mode for past entries
  - Date restrictions (can't journal future dates)
- **Streak Tracking:** Maintains daily journaling streaks
- **Streak Recovery:** Offers recovery options when streaks are broken

### 2. Monthly Planner
**Location:** Accessible via hourglass icon from Home

**Features:**
- **Task Management:**
  - Create tasks with categories (Work, Personal, Health, etc.)
  - Set recurring tasks (daily, weekly, monthly)
  - One-time tasks with specific dates
  - Task completion tracking
- **Calendar View:**
  - Monthly grid layout
  - Task distribution across days
  - Visual task indicators
  - Quick task completion toggle
- **Task Categories:**
  - Work
  - Personal
  - Health
  - Social
  - Learning
  - Creative
  - Finance
  - Other
- **Dopamine Tracker:**
  - Visual graph of task completion
  - Daily statistics
  - Perfect days tracking
  - Momentum building

### 3. AI Assistant
**Location:** Accessible via crystal ball icon from Home

**Features:**
- **Conversational AI:** Chat interface for mental wellness support
- **Context-Aware:** Remembers conversation history
- **Pattern Recognition:** Analyzes journal entries for insights
- **Task Suggestions:** AI-powered task recommendations based on journal content
- **Follow-up Suggestions:** Contextual conversation prompts
- **Affirmations:** Personalized positive affirmations
- **History Panel:** View past conversations
- **Conversation Memory:** Maintains context across sessions

### 4. Mood Dashboard
**Location:** Accessible via moon phases icon from Home

**Features:**
- **XP System:**
  - Earn XP from journaling and tasks
  - Level progression
  - Visual XP bar
- **Quest System:**
  - Daily quests (journal entry, mood tracking)
  - Weekly quests (journal 5 days, complete 20 tasks)
  - Monthly quests (journal 20 days, write 10,000 words)
  - Quest expiration and rotation
  - XP rewards for completion
- **Streak Badges:**
  - 7, 14, 21, 30, 60, 90-day streak badges
  - Visual badge display
  - Locked/unlocked states
- **Achievement Badges:**
  - Various achievement categories
  - Badge gallery
  - Unlock notifications
- **Mood Analytics:**
  - 7, 30, 90, 365-day mood trends
  - Mood chart visualization
  - Period comparison
  - Insights and suggestions
- **Statistics:**
  - Current streak
  - Longest streak
  - Total entries
  - Average mood
  - Mood trends

### 5. Growth Garden
**Location:** Accessible via mushroom icon from Home

**Features:**
- **Gamification Hub:** Central location for all gamification features
- **Badge Gallery:** View all earned and locked badges
- **Quest Progress:** Track active quests
- **XP Overview:** See level and progress
- **Achievement Tracking:** Monitor all achievements

### 6. Gratitude Jar
**Location:** Accessible via jar icon from Home

**Features:**
- **Visual Jar:** Beautiful jar that fills as gratitudes are added
- **Add Gratitudes:**
  - Write gratitude entries
  - Rate mood (1-5)
  - Date tracking
- **Random Gratitude:** Pull a random gratitude for inspiration
- **Gratitude List:** View recent gratitudes
- **Edit/Delete:** Manage gratitude entries
- **Fill Percentage:** Visual indicator of jar fullness
- **Color-Coded Dots:** Mood-based coloring inside jar

### 7. Time Capsule
**Location:** Accessible via time capsule icon from Home

**Features:**
- **Create Capsules:**
  - Write messages to future self
  - Set unlock date (30, 90, or 365 days)
  - Record current mood
  - List current goals
- **Locked Capsules:**
  - Countdown to unlock
  - Secure storage
  - Visual lock indicator
- **Unlocked Capsules:**
  - Read past messages
  - Mood comparison (then vs now)
  - Goal progress tracking
  - Reflection prompts
- **Interactive Features:**
  - Check off achieved goals
  - Compare mood changes
  - Celebrate growth

## Technical Architecture

### Frontend
**Framework:** React
**Routing:** React Router
**State Management:** React Context API
**Styling:** Tailwind CSS
**Charts:** Chart.js / react-chartjs-2
**Icons:** Custom SVG components

### Backend
**Server:** Node.js/Express
**Database:** Firebase/Firestore
**Authentication:** Firebase Auth
**API:** RESTful endpoints

### Key Technologies
- **React Hooks:** useState, useEffect, useContext
- **Context Providers:** AuthContext for user management
- **Custom Hooks:** Pattern recognition, mood insights
- **API Utilities:** Centralized API calls
- **Toast Notifications:** User feedback system

### File Structure
```
src/
├── components/          # Reusable UI components
├── pages/              # Main page components
├── contexts/           # React contexts
├── utils/              # Utility functions
├── constants/          # App constants
└── lib/                # Third-party integrations
```

### API Endpoints
**Journal:**
- POST /journal/add
- GET /journal/entries
- PUT /journal/update
- DELETE /journal/delete

**Tasks:**
- POST /tasks/add
- GET /tasks/list
- PUT /tasks/complete
- DELETE /tasks/delete

**Mood:**
- GET /mood/history
- GET /mood/analytics
- GET /mood/insights

**Gamification:**
- GET /user/stats
- GET /quests/active
- POST /quests/complete
- GET /badges/earned

**Gratitude:**
- POST /gratitude/add
- GET /gratitude/all
- GET /gratitude/random
- DELETE /gratitude/:id

**Time Capsule:**
- POST /timecapsule/create
- GET /timecapsule/list
- GET /timecapsule/:id

**AI Assistant:**
- POST /ai/chat
- POST /ai/analyze
- GET /ai/suggestions
